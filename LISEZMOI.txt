L'ATELIER DU TRACÉ : PASSAGE SUR atelier-du-trace.fr

Ce zip contient les pages du site mises à jour pour la nouvelle adresse.
Il ne contient PAS liens.js : vos liens Payhip et newsletters restent tels quels.

1. GitHub > dépôt > Settings > Pages > Custom domain : atelier-du-trace.fr > Save.
2. Envoyez le contenu de ce zip dans le dépôt (remplacez les fichiers existants).
   Le fichier CNAME garde le domaine même si vous remplacez tout le dépôt.
3. Chez OVHcloud, zone DNS : 4 enregistrements A (@) vers
   185.199.108.153 / 185.199.109.153 / 185.199.110.153 / 185.199.111.153
   et un CNAME "www" vers goldenmenu-free.github.io.
4. Attendez la propagation (jusqu'à 24 h), puis cochez "Enforce HTTPS".
5. Google Search Console : ajoutez atelier-du-trace.fr, puis le sitemap
   https://atelier-du-trace.fr/sitemap.xml
